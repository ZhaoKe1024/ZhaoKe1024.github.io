MiniOpt collapses the pipeline from a natural-language problem to executable solver code into
**one verifiable task**: the chain of thought must produce a five-element optimization formulation
(Sets / Parameters / Variables / Objective / Constraints) and choose a solver, while the answer must be a
single runnable **Pyomo** program. Training is a SFT warm-up followed by two-stage RL with **OptReward**
(format gate + five-element score + execution accuracy) and **OptGRPO** (no KL penalty, asymmetric
clipping with `eps_high = 0.28`, token-level loss). MiniOpt-7B reaches **64.76%** average
solving accuracy on eight benchmarks; MiniOpt-3B reaches 59.65%.
