We present **CAMTP**, the championship solution of the *Autonomous Travel Itinerary Planning
Challenge* at IJCAI'25. The core is **NL2C2DSL**: instead of asking an LLM to emit a DSL directly, we
extract 44 classes of structured constraints, correct ambiguous place names with BM25 retrieval, and
convert constraints into the DSL with deterministic code mapping. Six specialized agents (intercity
transport, attraction recommendation, path planning, hotel/restaurant, itinerary synthesis, refinement)
cooperate, with the daily route sequencing solved as a **VRP-TW** with OR-Tools.
